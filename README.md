## Focus

- **NVMe and SSD systems** — host/device I/O paths, queueing, latency, and device behavior
- **Storage firmware** — flash translation layers, garbage collection, mapping, and data placement
- **High-performance I/O** — SPDK, user-space storage stacks, and near-data processing
- **Storage intelligence** — workload analysis, caching, and anomaly detection
- **System software** — operating systems, networking, and efficient ML serving

## Selected work

| Project | Description |
| --- | --- |
| [NDT-BPE](https://github.com/doogunwo/NDT-BPE) | An SPDK-based near-data processing framework for storage-side data-path exploration |
| [storage-system](https://github.com/doogunwo/storage-system) | Storage systems coursework covering QEMU, libnvme, ZNS, and FTL design |
| [DiskAnomaly](https://github.com/doogunwo/DiskAnomaly) | LSTM-based anomaly analysis and visualization for block I/O traces |
| [snapcache](https://github.com/doogunwo/snapcache) | Go implementations for experimenting with cache eviction policies |
| [Mini-IPS](https://github.com/doogunwo/Mini-IPS) | A compact HTTP intrusion prevention system built around Linux networking |
